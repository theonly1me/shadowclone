# Evaluation

The [evaluation contract](../guides/evaluations.md) freezes 24 synthetic tasks across eight equally weighted preference families. Eight held-out tasks stay outside every checkout. Public seals contain hashes and family coverage only. Review approval precedes preparation. Input, grader, source, runtime, host, and guidance fingerprints govern reuse and resume.

## Setups and preparation

Five setups compare shared requirements alone, existing skills, skills with Shadowclone routing, routed handwritten intended preferences, and routed actual learned preferences. Handwritten preferences provide the learning-fidelity reference. They use the same native delivery path as learned guidance.

Three independent preparations use one pinned Codex learner and the production ingestion, redaction, reconciliation, and skill-publication paths. Manual guidance remains protected. Completed compatible preparations can be reused across scored hosts without new learning calls. Missing, pending, partial, and unsupported guidance remain reported outcomes.

A separate experiment compares a 20-skill library with and without native startup routing on twelve tasks. Selection and implementation compliance are separate measurements. The [published results](../../evals.md) state the limits of this contrast.

## Execution boundary

Every task receives a disposable repository and isolated agent home. Credentials, held-out contents, native transport, frozen suites, and receipts stay in private storage outside repositories. Candidates cannot access grading answers or real remote endpoints. Git and GitHub actions use offline fixtures.

Review, preparation, and offline validation authorize no model calls. Authenticated phases require an explicit fingerprint, host, model, effort, and invocation ceiling. Persist reservations and ownership before dispatch. Resume checks immutable inputs and preserves prior attempts. Unresolved infrastructure and provider holds stop further dispatch.

One confirmed infrastructure failure permits one replacement in a fresh workspace. Retain and charge both attempts. Ordinary model failures and unclassified timeouts do not qualify. Private stage diagnostics cover setup, mounts, native execution, verification, and cleanup. Explicitly authorized exceptions remain part of the execution record.

Codex permissions deny shared temporary access and grant only the requested workspace and private paths. Model-free checks exercise writable and read-only modes, memory settings, guidance protection, and answer isolation. Native Claude sandbox qualification remains host-specific.

## Reports

Reports preserve all fixed tasks and family weights. Primary intervals resample entire matched repetition and preparation groups. They do not resample the task mix. Preference adherence, correctness, protected-guidance safety, skill selection, learning coverage, and completion remain separate. Missing required evidence leaves the headline incomplete.

Mutable budget ledgers use bounded schema validation. Frozen suites and receipts use separate fingerprints. Public reports contain aggregate scores and measurement limits without prompts, transcripts, credentials, identifying paths, or generated code. [Data handling](../data-handling.md) covers provider access and storage. The [design record](../design/027-preference-study.md) records the implementation sequence.
