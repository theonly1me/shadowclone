# @shadowclone/briefs

Writes a task brief for one live session after a turn ends. A brief names the task, states its goal and what the agent did, and says whether the session asks a question, finished, or cannot continue.

## Owns

- `src/writer.ts`: `writeBrief`, with the lock, the hour limit, the unchanged message check, and the outcome of each run.
- `src/request.ts`: the request to the model and the strict schema of its answer.
- `src/answer.ts`: `briefFromAnswer`, which checks the answer and bounds each field after `redactSecrets`.
- `src/model.ts`: `fastTierModel`, the fast tier call to the session's own engine with no tools.
- `src/machine.ts`: `writeMachineBrief`, which checks the effective config and the managed policy for `shadowclone live brief`.

## Rules

- Do nothing unless `remote.task-briefs` is on in the effective config, and the managed policy allows the engine of the session.
- Send the model only the redacted first and latest prompt from the task file and the redacted last message. Never send a tool input or output, or thinking.
- Use the fast tier of the session's own engine, so no new provider receives the text. The run allows no tools.
- Tell the model that the session text is data, not instructions. Replace the data tags in the session text.
- Hold one lock for each session. Give each call 60 seconds. Allow `briefCallsPerHour` calls in one hour for each session, and count failed calls.
- Make no call when the last message did not change since the last brief.
- A failed call or an answer outside the schema keeps the earlier brief. The writer never fails the hook, because it runs in its own process.
- Log and print only ids and outcomes, never session text.
